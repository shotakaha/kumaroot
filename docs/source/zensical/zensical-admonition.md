# 注釈したい

```md
!!! note "注釈したい"
    ここに注釈したい内容を書く。
    複数行にわたる場合は、行末に半角スペースを2つ入れることで改行できる。
    さらに改行したい場合は、行末に半角スペースを2つ入れる。

    - 箇条書きも可能
    - 箇条書きも可能
    - 箇条書きも可能

    > 引用も可能
    > 引用も可能
```

`!!!`のあとにタイプを書くと、色とアイコンのついた注釈ボックスを挿入できます。
`admonition`や`callout`とも呼ばれます。
本文はタイプ行のあと、半角スペース4つ（または1タブ）でインデントします。
`"タイトル"`を省略するとタイプ名がそのままタイトルになり、`""`（空文字）にするとタイトル行が消えます。

タイプにはそれぞれ決まった色系統があります。エイリアスを使っても色とアイコンは代表タイプと同じになります。

## メモしたい（`note`）

青系。もっとも汎用的な補足。

```md
!!! note "メモのタイトル"
    ここにメモの内容を書く。
```

## 概要を示したい（`abstract`）

青系。冒頭の要約やTL;DRに使う。エイリアスは`summary`、`tldr`。

```md
!!! abstract "概要のタイトル"
    ここに概要の内容を書く。
```

## 補足情報を示したい（`info`）

シアン系。付随する情報やToDo。エイリアスは`todo`。

```md
!!! info "補足のタイトル"
    ここに補足の内容を書く。
```

## ヒントしたい（`tip`）

緑系。オススメのやり方やコツ。エイリアスは`hint`、`important`。

```md
!!! tip "ヒントのタイトル"
    ここにヒントの内容を書く。
```

## 成功を示したい（`success`）

緑系。うまくいったケースや推奨される手順。エイリアスは`check`、`done`。

```md
!!! success "成功のタイトル"
    ここに成功の内容を書く。
```

## 質問したい（`question`）

黄系。FAQやよくある疑問。エイリアスは`help`、`faq`。

```md
!!! question "質問のタイトル"
    ここに質問の内容を書く。
```

## 警告したい（`warning`）

オレンジ系。注意して読んでほしい内容。エイリアスは`caution`、`attention`。

```md
!!! warning "警告のタイトル"
    ここに警告の内容を書く。
```

## 失敗を示したい（`failure`）

赤系。避けるべきやり方や失敗するケース。エイリアスは`fail`、`missing`。

```md
!!! failure "失敗のタイトル"
    ここに失敗の内容を書く。
```

## 危険を示したい（`danger`）

赤系。データ損失など取り返しのつかない操作。エイリアスは`error`。

```md
!!! danger "危険のタイトル"
    ここに危険の内容を書く。
```

## 不具合を示したい（`bug`）

紫系。既知のバグや不具合。

```md
!!! bug "不具合のタイトル"
    ここに不具合の内容を書く。
```

## 具体例を示したい（`example`）

紫系。使用例やサンプル。

```md
!!! example "具体例のタイトル"
    ここに具体例の内容を書く。
```

## 引用したい（`quote`）

グレー系。出典のある引用。エイリアスは`cite`。

```md
!!! quote "引用のタイトル"
    ここに引用の内容を書く。
```

## 折りたたみたい（`???`）

`!!!`を`???`にすると折りたたみボックスになります。
初期状態は閉じており、クリックで開きます。
`???+`にすると最初から開いた状態で表示されます。

```md
??? note "クリックで開く"
    初期状態は閉じている。

???+ note "最初から開いている"
    展開済みで表示される。
```
