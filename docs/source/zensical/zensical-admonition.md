# 注釈したい

```md
!!! note "注釈したい"
    ここに注釈したい内容を書く。
    複数行にわたる場合は、行末に半角スペースを2つ入れることで改行できる。
    さらに改行したい場合は、行末に半角スペースを2つ入れる。

    - 箇条書きも可能
    - 箇条書きも可能
    - 箇条書きも可能

    > 引用も可能
    > 引用も可能
```

`!!!`のあとにタイプを書くと、色とアイコンのついた注釈ボックスを挿入できます。
`admonition`や`callout`とも呼ばれます。
本文はタイプ行のあと、半角スペース4つ（または1タブ）でインデントします。
`"タイトル"`を省略するとタイプ名がそのままタイトルになり、`""`（空文字）にするとタイトル行が消えます。

タイプにはそれぞれ決まった色系統があります。
エイリアスを使っても色とアイコンは代表タイプと同じになります。

## メモしたい（`note`）

```md
!!! note "メモのタイトル"
    ここにメモの内容を書く。
```

`note`は、汎用的なメモを表示するためのタイプです。
青系です。

## 概要したい（`abstract`）

```md

```

`abstract`は、概要や要約を表示するためのタイプです。
青系です。

## 折りたたみたい（`???`）

```md
??? note "クリックで開く"
    初期状態は閉じている。

???+ note "最初から開いている"
    展開済みで表示される。
```

`!!!`を`???`にすると折りたたみボックスになります。
初期状態は閉じており、クリックで開きます。
`???+`にすると最初から開いた状態で表示されます。
