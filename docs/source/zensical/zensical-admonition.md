# 注釈したい

```md
!!! note "注釈したい"
    ここに注釈したい内容を書く。
    複数行にわたる場合は、行末に半角スペースを2つ入れることで改行できる。
    さらに改行したい場合は、行末に半角スペースを2つ入れる。

    - 箇条書きも可能
    - 箇条書きも可能
    - 箇条書きも可能

    > 引用も可能
    > 引用も可能
```

`!!!`で注釈を挿入できます。

## ヒントしたい（`tip` / `hint`）

```md
!!! tip "ヒントのタイトル"
    ここにヒントの内容を書く。
```

## エラーしたい（`error` / `danger`）

```md
!!! error "エラーのタイトル"
    ここにエラーの内容を書く。
```

## 警告したい（`warning` / `caution`）

```md
!!! warning "警告のタイトル"
    ここに警告の内容を書く。
```

## 注意したい（`important` / `attention`）

```md
!!! important "注意のタイトル"
    ここに注意の内容を書く。
```

## 余談したい（`note` / `info`）

```md
!!! note "余談のタイトル"
    ここに余談の内容を書く。
```

## 参考したい（`seealso` / `reference`）

```md
!!! seealso "参考のタイトル"
    ここに参考の内容を書く。
```

## 引用したい（`quote` / `cite`）

```md
!!! quote "引用のタイトル"
    ここに引用の内容を書く。
```
