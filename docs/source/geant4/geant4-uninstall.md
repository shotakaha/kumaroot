# アンインストールしたい（`geant4`）

```console
// ステップ1：バージョンごとの作業ディレクトリに移動する
$ cd ~/geant4/v11.4.3/

// ステップ2：ビルド用ディレクトリを削除する
$ rm -r build

// ステップ3：インストール先のディレクトリを削除する
$ rm -r install
```

`install`ディレクトリと`build`ディレクトリを削除することで、Geant4をアンインストールできます。
`install`を削除すると、そのバージョンの実行ファイルやライブラリは使えなくなります。

:::{note}

ここまでで紹介した手順は個人利用を想定しているため、システム全体にインストールしていません。
そのため`install`と`build`を削除するだけでアンインストールできます。
他のバージョン（`v11.X.Y`）のディレクトリには影響しません。

:::

## 完全にアンインストールしたい

```console
// ステップ1：ソースコードを含むバージョンごとのディレクトリを削除する
$ cd ~/geant4/
$ rm -r v11.4.3

// ステップ2：ダウンロードしたアーカイブを削除する
$ rm archives/geant4-v11.4.3.zip
```

ソースコードやアーカイブも含めて削除すれば、完全にアンインストールできます。
アーカイブは再ダウンロードできるので、ディスク容量を節約したい場合だけ削除してください。
