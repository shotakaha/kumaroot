# プロセス一覧したい（`ps`）

```console
$ ps aux
```

`ps`は、実行中のプロセスを表示するコマンドです。

## 特定のプロセスを探したい（`grep`）

```console
$ ps aux | grep プロセス名
```

`ps aux`の結果を[grep](./command-grep.md)にパイプすると、プロセス名で絞り込めます。

## 表示する項目を選びたい（`-o`）

```console
$ ps -o pid,%cpu,%mem,comm
```

`-o`オプションで、表示する項目をキーワードで指定できます。
必要な情報だけに絞り込んで見やすくしたいときに使います。

## コマンド名を短く表示したい（`-c`）

```console
$ ps aux -c
```

`-c`オプションで、コマンド列をフルパスや引数なしの実行ファイル名だけに短縮できます。

## 使用率順に並べたい（`-r` / `-m`）

```console
// CPU使用率順
$ ps aux -r

// メモリ使用率順
$ ps aux -m
```

`-r`オプションでCPU使用率順、`-m`オプションでメモリ使用率順にソートできます。
重いプロセスを探したいときに使います。

## 特定のプロセスIDを確認したい（`-p`）

```console
$ ps -p プロセスID
```

`-p`オプションで、指定したプロセスIDの情報だけを表示できます。
