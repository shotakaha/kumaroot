# ファイルを開きたい（`open` / `xdg-open`）

```console
$ open ファイル名
$ xdg-open ファイル名
```

`open`はターミナルからファイルを開くコマンドです。
Linuxでは`xdg-open`を使います。

## 現在のディレクトリを開きたい

```console
$ open .
```

引数にディレクトリ名を指定できます。
`.`でカレントディレクトリを開く作業は、頻繁に使います。

## アプリを開きたい（`open -a`）

```console
$ open -a "アプリ名"
$ open -a "Adobe Illustrator"
$ open -a Adobe\ Illustrator
```

`-a`で、アプリを指定して開くことができます。
アプリ名に空白が含まれる場合は、`\`（バックスラッシュ）でエスケープする、もしくは、アプリ名全体を`"`（クォート）で囲む必要があります。

## ファインダーで開きたい（`open -R`）

```console
$ open -R ファイル名
```

`-R`で、指定したファイルを選択した状態で、ファインダーを開くことができます。

:::{note}

`open ディレクトリ`は、`open -R ディレクトリ`と同じです。

:::
