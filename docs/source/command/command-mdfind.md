# ファイルを探したい（`mdfind`）

```console
$ mdfind ファイル名
$ mdfind コンテンツの内容
```

`mdfind`は、macOSでSpotlight検索できるコマンドです。
ファイル名やコンテンツの一部で探すことができてとても便利です。
検索結果が多い場合、`rg`などの検索コマンドにパイプして使うことが多いです。

## 検索範囲を絞りたい（`-onlyin`）

```console
$ mdfind -onlyin ディレクトリ 検索キーワード
```

`-onlyin`オプションで、検索対象を指定したディレクトリ以下に限定できます。
`Downloads`や特定のプロジェクトディレクトリなど、探したい場所がわかっている場合に使います。

## ファイル名だけで探したい（`-name`）

```console
$ mdfind -name ファイル名
```

`-name`オプションで、コンテンツを見ずにファイル名だけを対象に検索できます。
同じキーワードがコンテンツにも含まれるファイルが多いときに、ノイズを減らせます。

## 件数だけ知りたい（`-count`）

```console
$ mdfind -count 検索キーワード
```

`-count`オプションで、マッチしたファイルのパスではなく件数だけを表示できます。
