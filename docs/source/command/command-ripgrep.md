# テキストを検索したい（`ripgrep`）

```console
$ brew install ripgrep
$ rg --version
ripgrep 14.1.0
```

`rg`はRust製の高速[grep](./command-grep.md)です。
{file}`.gitignore`に書かれているファイルは無視してくれます。
検索結果の該当箇所がデフォルトで色付けされます。
デフォルトの検索パターンは`grep -E`と同じ拡張正規表現として扱われます。

:::{hint}

Rust製なのでバイナリーをインストールするだけで使えます。
管理者権限のないサーバーにも導入しておくと便利です。

:::

:::{seealso}

- [](./command-grep.md)

:::

## 大文字/小文字を区別せずに探したい（`-i`）

```console
$ rg -i 検索パターン
```

`-i`オプションで、大文字/小文字を区別せずに検索できます。
`rg`はデフォルトでスマートケース（パターンに大文字を含む場合のみ区別）なので、
`grep`より意識する機会は少なめです。

## マッチしなかった行を探したい（`-v`）

```console
$ rg -v 検索パターン
```

`-v`オプションで、検索パターンにマッチしなかった行だけを書きだせます。

## 行番号を表示したい（`-n`）

```console
$ rg -n 検索パターン
```

`rg`は`grep`と異なり、デフォルトで行番号が表示されます。
表示したくない場合は`-N`（`--no-line-number`）を使います。

## マッチした数だけ知りたい（`-c`）

```console
$ rg -c 検索パターン
```

`-c`オプションで、マッチした行の内容ではなく、行数だけを書きだせます。

## マッチしたファイル名だけ知りたい（`-l`）

```console
$ rg -l 検索パターン
```

`-l`オプションで、マッチした内容ではなく、ファイル名だけを書きだせます。

## ディレクトリを再帰的に探したい（デフォルト）

```console
$ rg 検索パターン 検索パス
```

`grep`は`-r`オプションが必要ですが、`rg`はデフォルトで再帰検索します。
`.gitignore`に書かれたファイルは自動的に除外されます。
除外を無視してすべて検索したい場合は`-u`（`--unrestricted`）を使います。

## ファイルの種類で絞り込みたい（`-t` / `--type`）

```console
// Pythonファイルだけを検索したい
$ rg -t py 検索パターン

// 対応しているファイルタイプの一覧を見たい
$ rg --type-list
```

`-t`オプションで、拡張子を意識せずにファイルの種類を指定して検索できます。
`find -name "*.py"`のようなパターン指定より簡潔に書けます。

## globパターンで絞り込みたい（`-g` / `--glob`）

```console
// テストディレクトリを除外して検索したい
$ rg -g "!test/**" 検索パターン 検索パス
```

`-g`オプションで、`.gitignore`と同じ書き方のglobパターンを使って
検索対象のファイル・ディレクトリを絞り込めます。
`test/**`のようなパターンは検索パスの先頭からのパスにマッチするため、
`検索パス`を省略してカレントディレクトリを起点に検索するのが基本の使い方です。

## 前後の行も一緒に見たい（`-A` / `-B` / `-C`）

```console
// マッチした行の後を3行表示したい
$ rg -A 3 検索パターン

// マッチした行の前を3行表示したい
$ rg -B 3 検索パターン

// マッチした行の前後を3行ずつ表示したい
$ rg -C 3 検索パターン
```

`-A`（after）・`-B`（before）・`-C`（context）オプションで、
マッチした行だけでなく前後の行もあわせて確認できます。

## マッチした文字列を置換したい（`-r` / `--replace`）

```console
$ rg 検索パターン -r 置換文字列
```

`-r`オプションで、マッチした文字列を置換して表示できます。
ファイルの内容そのものは書き換わりません。

## 圧縮ファイルを検索したい（`-z` / `--search-zip`）

```console
$ rg -z 検索パターン 検索するファイル.gz
```

`-z`オプションで、`gzip`などで圧縮されたファイルを展開せずに検索できます。
`grep`系コマンドの`zgrep`に相当します。
