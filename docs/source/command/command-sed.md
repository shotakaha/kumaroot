# テキストを置換したい（`sed`）

```console
$ sed 's/正規表現/置換文字列/' ファイル名
$ コマンド | sed 's/正規表現/置換文字列/g'
```

`sed`は、ファイルの中身をテキスト置換できるコマンドです。
正規表現パターンで検索し、マッチしたテキストを置換できます。
`s/検索パターン/置換パターン/`という特徴的な引数を使います。

コマンドの実行結果をパイプで受け取り、`sed`で置換して、さらに別のコマンドにパイプしたり、ファイルに書き込む使い方が多いです。

:::{note}

引数が特徴的なので、Twitterなどで直前の投稿の誤字を訂正するツイートをする場合、
`s/誤字のパターン/正しい文字列/`
のように書き込むひともいます。

:::

## 部分置換したい（`s/.../.../`）

```console
$ echo "aaa" | sed 's/a/b/'
baa
```

`s/検索パターン/置換パターン/`だけだと、1行につき最初にマッチした箇所だけを置換します。

## すべて置換したい（`s/.../.../g`）

```console
$ echo "aaa" | sed 's/a/b/g'
bbb
```

`g`（`global`）フラグをつけると、1行の中でマッチしたすべての箇所を置換します。

## ファイルを直接書き換えたい（`-i`）

```console
$ sed -i '' 's/検索パターン/置換パターン/' ファイル名
```

`-i`オプションで、標準出力に結果を表示するのではなく、ファイルの中身を直接書き換えられます。

:::{caution}

macOSの`sed`（BSD版）は、`-i`のあとにバックアップ用の拡張子を必ず指定する必要があります。
バックアップが不要な場合も、`-i ''`のように空文字列を渡します。
Linuxでよく使われるGNU版の`sed`は`-i`だけで動作するため、そのままではmacOSでエラーになります。

:::

## 特定の行だけ置換したい（行番号指定）

```console
$ printf "aaa\naaa\naaa\n" | sed '2s/aaa/bbb/'
aaa
bbb
aaa
```

`s`コマンドの前に行番号をつけると、その行だけに置換を適用できます。

## 後方参照を使いたい（`\1`）

```console
$ echo "2024-01-15" | sed -E 's/([0-9]+)-([0-9]+)-([0-9]+)/\3\/\2\/\1/'
15/01/2024
```

`()`で囲んだ部分は、マッチした文字列を`\1`・`\2`・`\3`のように置換パターン側で再利用できます。
`-E`オプションで拡張正規表現を有効にすると、`()`をエスケープなしで使えます。
