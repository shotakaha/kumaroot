# テキストを置換したい（`sed`）

```console
$ sed 's/正規表現/置換文字列/' ファイル名
$ コマンド | sed 's/正規表現/置換文字列/g'
```

`sed`は、ファイルの中身をテキスト置換できるコマンドです。
正規表現パターンで検索し、マッチしたテキストを置換できます。
`s/検索パターン/置換パターン/`という特徴的な引数を使います。

:::{note}

引数が特徴的なので、Twitterなどで直前の投稿の誤字を訂正するツイートをする場合、
`s/誤字のパターン/正しい文字列/`
のように書き込むひともいます。

:::

```{seealso}
[sd](./command-sd.md)というRust製の代替コマンドがあります。
こちらのほうが引数が覚えやすそうです。
```
