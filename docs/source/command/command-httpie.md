# HTTPリクエストしたい（`httpie`）

```console
$ http https://example.com
```

`httpie`は、HTTPリクエストを操作できるHTTPクライアントです。

## インストールしたい（`httpie`）

```console
// CLI版
$ brew install httpie

// GUI版
$ brew install --cask httpie-desktop
```

`httpie`はHomebrewでインストールできます。
CLI版のフォーミュラ名は`httpie`、
GUI版のCask名は`httpie-desktop`です。
