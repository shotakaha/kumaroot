# HTTPリクエストしたい（`xh`）

```console
$ xh https://example.com
```

`xh`は、HTTPリクエストを送信するコマンドです。
[curl](./command-curl.md)のRust代替コマンドです。

- [](./command-curl.md)

:::

## インストールしたい（`xh`）

```console
$ brew install xh
$ xh --version
xh 0.26.2
-native-tls +rustls
```

`xh`はHomebrewでインストールできます。
