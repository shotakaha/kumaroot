# 圧縮・展開したい（`gzip` / `gunzip`）

```console
// ファイルを圧縮する
$ gzip ファイル名
// ファイル名.gzが作成される
// ファイルは削除される

// ファイルを展開する
$ gunzip ファイル名.gz
$ gzip -d ファイル名.gz
```

`gzip`は、ひとつのファイルを圧縮するコマンドです。
`gunzip`は、圧縮されたファイルを展開するコマンドです。
`gzip -d`でも展開できます。

## 圧縮したい（`gzip`）

```console
$ gzip [ファイル名]
// [ファイル名].gzが作成される
// [ファイル名]は削除される
```

`gzip`コマンドで、指定したファイルをgzip形式で圧縮できます。
元のファイルは削除され、`.gz`が付いたファイルが作成されます。

```console
$ gzip --keep [ファイル名]
// [ファイル名].gzが作成される
// [ファイル名]は残る
$ gzip -k [ファイル名]
```

`--keep`（`-k`）オプションで、元のファイルを残すこともできます。

## 展開したい（`gunzip` / `gzip -d`）

```console
$ gunzip [ファイル名].gz
$ gzip -d [ファイル名].gz
// [ファイル名]が作成される
// [ファイル名].gzは削除される
```

`gunzip`もしくは`gzip -d`で、gzip形式の圧縮ファイルを展開できます。
元のファイルは削除されます。

```console
$ gzip -dk [ファイル名].gz
// [ファイル名]が作成される
// [ファイル名].gzは残る
```

`--keep`（`-k`）オプションで、元の圧縮ファイルを残すこともできます。

## 標準出力したい（`-c`）

```console
$ gzip -c ファイル名 > ファイル名.gz
$ gzip -c -d ファイル名.gz > ファイル名
```

`-c`オプションで、圧縮／展開した結果を標準出力に表示できます。
出力した結果をリダイレクトしてファイルに書き出したり、
パイプして別のコマンドに渡したりできます。

:::{hint}

ウェブサイトのログを解析（[goaccess](./command-goaccess.md)）するときに使っています。

```console
$ gzip -cd ログファイル.gz | goaccess --log-format COMBINED -o ログファイル.html
```

:::
