# pingしたい（`ping` / `gping`）

```console
$ ping ホスト名
$ ping IPアドレス
```

`ping`は、ネットワークの接続確認をするコマンドです。
調べたいホスト名やIPアドレスを指定して、接続できるかどうかを確認できます。
ネットワーク接続で困ったときに、まず使ってみるコマンドです。

## インストールしたい（`gping`）

```console
$ brew install gping
gping 1.20.4
```

`gping`は、`ping`の結果をグラフで表示できるコマンドです。
Homebrewでインストールできます。

## 接続確認したい

```console
$ ping 8.8.8.8  # Googleの公開DNSサーバー
$ ping 8.8.4.4  # Googleの公開DNSサーバー（代替）
```

`8.8.8.8`はGoogleが用意している公開DNSサーバーのIPアドレスです。
新しいルーターに接続したときや、ネットワークが不安定なときに、まずここに向けて`ping`を打ってみるとよいでしょう。

## 回数を設定したい

```console
$ ping -c 5 IPアドレス  # 5回実行して終了
```

`-c`で、`ping`を打つ回数を設定できます。
デフォルトでは無限回になっており、`Ctrl + c`で終了できます。
