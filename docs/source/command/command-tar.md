# 圧縮・展開したい（`tar`）

```console
// 複数のファイルをまとめて圧縮
$ tar czvf 圧縮ファイル.tar.gz ファイル1 ファイル2

// 圧縮されたファイルを展開
$ tar xzvf 圧縮ファイル.tar.gz
```

`tar`コマンドで、複数のファイルをまとめて圧縮したり、圧縮されたファイルを展開できます。
`czvf`で圧縮、`xzvf`で展開します。
`f`はファイル名を指定するオプションなので、末尾に付ける必要があります。

:::{note}

`tar`は`Tape ARchive`の略です。
もともとは複数ファイルをひとつのファイルにまとめるコマンドでした。
そこに`z`などの圧縮オプションが追加され、圧縮／解凍コマンドとして使えるようになっています。

:::

:::{warning}

引数に与えるファイル名のならびには気をつけましょう。
さもないと、大事なデータが消えてしまうことになります。
（経験者）

:::

## 圧縮したい（`tar czvf`）

```console
// [C]reate g[Z]ip [F]iles
$ tar czvf 圧縮ファイル.tar.gz ファイル1 ファイル2
$ tar czvf 圧縮ファイル.tar.gz -C ディレクトリ名 .
```

`czvf`で、gzip形式の圧縮ファイルを作成できます。
`-C ディレクトリ名`オプションで、指定したディレクトリをまるごと圧縮できます。
ファイル名やディレクトリ名は相対パスでも絶対パスでも指定できます。

## 特定のファイルを除外したい（`--exclude`）

```console
$ tar czvf 圧縮ファイル.tar.gz --exclude='*.log' ディレクトリ名
```

`--exclude`オプションで、パターンにマッチするファイルを圧縮対象から除外できます。

## 中身を確認したい（`tar tzvf`）

```console
// [T]able of contents g[Z]ip [V]erbosely [F]ile
$ tar tzvf 圧縮ファイル.tar.gz
```

`tzvf`で、展開せずにアーカイブの中身を一覧表示できます。
大きなファイルを不用意に展開する前の確認に便利です。

## 解凍したい（`tar xzvf`）

```console
// e[X]tract g[Z]ip [F]ile
$ tar xzvf 圧縮ファイル.tar.gz
```

`xzvf`で、gzip形式の圧縮ファイルを解凍できます。

## 特定のファイルだけ展開したい

```console
$ tar xzvf 圧縮ファイル.tar.gz ファイル名
```

`xzvf`のあとにファイル名（またはパターン）を指定すると、アーカイブの中から該当するファイルだけを展開できます。

## アーカイブしたい（`tar cf` / `tar xf`）

```console
// [C]reate [F]iles
$ tar cf アーカイブファイル.tar ファイル1 ファイル2

// e[X]tract [F]iles
$ tar xf アーカイブファイル.tar
```

`cf`で、複数のファイルをひとつにまとめたアーカイブファイルを作成できます。
`xf`で、アーカイブファイルを展開できます。

## 圧縮形式を変更したい

```console
// bzip2形式で圧縮
$ tar cjvf 圧縮ファイル.tar.bz2 ファイル1 ファイル2
$ tar --bzip2 -cvf 圧縮ファイル.tar.bz2 ファイル1 ファイル2

// xz形式で圧縮
$ tar cJvf 圧縮ファイル.tar.xz ファイル1 ファイル2
$ tar --xz -cvf 圧縮ファイル.tar.xz ファイル1 ファイル2

// zstd形式で圧縮
$ tar --zstd -cvf 圧縮ファイル.tar.zst ファイル1 ファイル2
```

`z`（`--gzip`）でgzip形式、
`j`（`--bzip2`）でbzip2形式、
`J`（`--xz`）でxz形式の圧縮ファイルを作成できます。

`--zstd`でzstd形式、
`--lzip`でlzip形式、
`--lzma`でlzma形式の圧縮ファイルを作成できます。

展開時（`xvf`）は、圧縮形式を指定しなくても拡張子や中身から自動判別されます。
