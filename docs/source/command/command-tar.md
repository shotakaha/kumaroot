# 圧縮／解凍したい（`tar`）

```console
// 複数のファイルをまとめて圧縮
$ tar czvf 圧縮ファイル.tar.gz ファイル1 ファイル2

// 圧縮されたファイルを解凍
$ tar xzvf 圧縮ファイル.tar.gz
```

`tar`コマンドで、複数のファイルをまとめて圧縮したり、圧縮されたファイルを解凍できます。

`tar`は`Tape ARchive`の略で、もともとは複数ファイルをひとつのファイルにまとめるコマンドでした。
そこに`z`などの圧縮オプションが追加され、圧縮／解凍コマンドとして使うことができます。

:::{warning}

引数に与えるファイル名のならびには気をつけましょう。
さもないと、大事なデータが消えてしまうことになります。
（経験者）

:::

:::{seealso}

ひとつのファイルを圧縮するだけであれば、gzipやcompressというコマンドもあります。

:::

## 圧縮したい（`tar czvf`）

```console
// [C]reate g[Z]ip [F]iles
$ tar czvf 圧縮ファイル.tar.gz ファイル1 ファイル2
$ tar czvf 圧縮ファイル.tar.gz -C ディレクトリ名 .
```

`czvf`で、gzip形式の圧縮ファイルを作成できます。
`-C ディレクトリ名`オプションで、指定したディレクトリをまるごと圧縮できます。
ファイル名やディレクトリ名は相対パスでも絶対パスでも指定できます。

## 解凍したい（`tar xzvf`）

```console
// e[X]tract g[Z]ip [F]ile
$ tar xzvf 圧縮ファイル.tar.gz
```

`xzvf`で、gzip形式の圧縮ファイルを解凍できます。

## アーカイブしたい（`tar cf`）

```console
// [C]reate [F]iles
$ tar cf アーカイブファイル.tar ファイル1 ファイル2

// e[X]tract [F]iles
$ tar xf アーカイブファイル.tar
```

`cf`で、複数のファイルをひとつにまとめたアーカイブファイルを作成できます。
`xf`で、アーカイブファイルを展開できます。

## 中身を確認したい（`tar tzvf`）

```console
// [T]able of contents g[Z]ip [V]erbosely [F]ile
$ tar tzvf 圧縮ファイル.tar.gz
```

`tzvf`で、展開せずにアーカイブの中身を一覧表示できます。
大きなファイルを不用意に展開する前の確認に便利です。

## 特定のファイルを除外したい（`--exclude`）

```console
$ tar czvf 圧縮ファイル.tar.gz --exclude='*.log' ディレクトリ名
```

`--exclude`オプションで、パターンにマッチするファイルを圧縮対象から除外できます。

## 特定のファイルだけ展開したい

```console
$ tar xzvf 圧縮ファイル.tar.gz ファイル名
```

`xzvf`のあとにファイル名（またはパターン）を指定すると、アーカイブの中から該当するファイルだけを展開できます。
