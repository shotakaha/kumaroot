## インストールしたい（`nushell`）

```console
$ brew info nushell
$ brew install nushell
$ brew upgrade nushell

$ nu --version
0.115.0
```

`nushell`はHomebrewでインストールできます。
フォーミュラ名は`nushell`です。
コマンド名は`nu`です。
