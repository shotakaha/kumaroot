# 複雑なパイプしたい（`xargs`）

```console
$ コマンド | xargs コマンド
```

`xargs`は、あるコマンドの実行結果を、次のコマンドの引数に変換して渡すコマンドです。

通常のパイプ処理では、前のコマンドの実行結果は、次のコマンドの標準入力として渡されます。
このとき、標準入力に対応していないコマンドだと、処理ができません。
`xargs`を使って「引数」に変換することで、標準入力に対応していないコマンドでもパイプ処理が可能になります。

## ヌル区切りを受け取りたい（`--null` / `-0`）

```console
$ コマンド | xargs -0 コマンド
$ コマンド | xargs --null コマンド
```

`--null`（`-0`）で、入力の区切り文字をヌル文字（`\0`）に変更できます。

`xargs`はデフォルトで、入力を空白文字（スペース・タブ・改行）で区切って引数に変換します。
そのため、ファイル名に空白文字が含まれていると、1つのファイル名が複数の引数に分割されてしまいます。
ヌル文字（`\0` / `\0x00` / `U+0000`）はファイル名に含まれることがない文字コードなので、区切りとして安全です。

[find](./command-find.md)の`-print0`や[fd](./command-fd.md)の`-0`のように、
出力をヌル文字区切りにできるコマンドと組み合わせて使います。

:::{seealso}

- [](./command-find.md)
- [](./command-fd.md)

:::

## 確認プロンプトしたい（`--interactive` / `-p`）

```console
$ コマンド | xargs -p コマンド
$ コマンド | xargs --interactive コマンド
```

`--interactive`（`-p`）で、実行前に確認のプロンプトを挟むことができます。

## 空実行したくない（`--no-run-if-empty` / `-r`）

```console
$ コマンド | xargs -r コマンド
$ コマンド | xargs --no-run-if-empty コマンド
```

`--no-run-if-empty`（`-r`）で、入力が空の場合にコマンドを実行しないようにできます。

:::{seealso}

Linuxの`xargs`（GNU版）では、デフォルトで入力が空の場合でもコマンドを実行してしまうので、`-r`オプションをつける必要があります。

macOS標準の`xargs`（BSD版）は、デフォルトで入力が空の場合にコマンドを実行しませんが、GNU版との互換性のために、`-r`オプションが用意されています。

:::

## ファイルのパーミッションを一括変更したい

```console
// ファイル: 664に変更
$ find . -type f | xargs -d "\n" chmod 664

// ディレクトリ: 775に変更
$ find . -type d | xargs --delimiter="\n" chmod 775
```

`xargs`は`find`系の検索コマンドとの組み合わせることで力を発揮します。
ここでは`find`コマンドと`chmod`コマンドを組み合わせて、ファイルのパーミッションを一括して変更しています。

:::{caution}

`-d`（`--delimiter`）はGNU版`xargs`（Linux）のオプションです。
macOS標準の`xargs`（BSD版）では使えません。
macOSでは、次に紹介する`-0`（`--null`）を使いましょう。

:::

```console
// HTMLファイルに限定
$ find . -type f -name "*.html" -print0 | xargs -0 chmod 664
```

ファイルの種類を限定したい場合は`-name "*.拡張子"`のようにファイル名の一部を指定します。
ここでは`-name "*.html"`を指定子、HTMLファイルに限定しています。

ファイル名やディレクトリ名に空白文字や特殊文字が含まれている可能性があります。
`xargs`はデフォルトで空白文字で改行してしまうため、`--delimiter="\n"`で区切り文字を指定しています。

`-0`（`--null`）オプションについては、前述の「ヌル区切りを受け取りたい」を参照してください。

## 一括削除したい

```console
// 検索結果にヒットしたファイルをまとめて削除
$ find . -name "*.tmp" | xargs -p rm
```

`--interactive`（`-p`）で、実行前に`y/n`確認を挟むことができます。
`xargs -p rm`とすると、削除する前に確認のプロンプトを表示できます。

```console
// 検索結果をファイルに保存してから削除
$ fd -0 "検索パターン" > files.txt
$ cat files.txt
$ xargs -0 rm < files.txt
$ mv files.txt ${date +%Y%m%d}_removed_files.txt
```

削除の記録を残したい場合、対象となるファイルを一度ファイルに保存してから削除する方法もあります。

:::{note}

同様の実行結果は
`rm "検索パターン"`
でも得られます。
しかし、どのファイルが削除されるのか、確認が難しいです。

`xargs`の実用的なポイントとして
`fd "検索パターン"`の結果を一度ファイルに保存し、
`cat files.txt`で中身を確認、
問題がなければ`xargs -0 rm < files.txt`で削除、
のように確認→実行のフローが作れることです。

:::
