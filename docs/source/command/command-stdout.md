# リダイレクトしたい（`>`）

```console
// 標準出力をファイルに保存
$ コマンド 1> ファイル名

// 標準出力をファイルに追記
$ コマンド 1>> ファイル名

// 標準出力と標準エラー出力を別々に保存
$ コマンド 1> ファイル1 2> ファイル2
```

コマンドの実行結果は
標準出力（`stdout`）と
標準エラー出力（`stderr`）に出力されます。

実行結果は`>`でリダイレクトできます。
`1>`は標準出力のリダイレクト、
`2>`は標準エラー出力のリダイレクトです。

:::{note}

`>`は、`1>`の短縮形です。
このページでは、すべて`1>`と書くことにします。

:::

:::{seealso}

標準出力（`stdout`）と標準エラー出力（`stderr`）の区別は、Unixの初期からある概念です。
Unix哲学のひとつに「ひとつのことをうまくやる」というものがあり、あるコマンドの実行結果は、パイプ処理によって次のコマンドに渡すことができます。
このとき、実行エラーなどが混ざってしまうと、次のコマンドがスムーズに処理できません。

そのため、
標準出力には次の処理で利用できる結果を、
標準エラー出力には実行エラーや進捗状況など人間が確認するための情報を、
のように出力を切り替えられるようになっています。

:::

## 標準出力したい（`1>`）

```console
$ コマンド 1> ファイル名
$ コマンド 1>> ファイル名
```

`stdout`は、コマンドの実行結果の出力先です。
標準出力（`/dev/stdout`）のファイルディスクリプターは`fd = 1`に割り当てられているため、`1>`でリダイレクトできます。

## 標準エラー出力したい（`2>`）

```console
$ コマンド 2> ファイル名
$ コマンド 2>> ファイル名
```

`stderr`は、コマンドの進捗状況や実行結果のエラーなどの出力先です。
標準エラー出力（`/dev/stderr`）のファイルディスクリプターは`fd = 2`に割り当てられているため、`2>`でリダイレクトできます。

## 標準出力と標準エラー出力を保存したい（`&>`）

```console
$ コマンド &> ファイル名
$ コマンド &>> ファイル名
$ コマンド 1> ファイル名 2>&1        # 別の方法
$ コマンド 1>> ファイル名 2>&1       # 別の方法
```

`&>`で、`stdout`と`stderr`をまとめて同じファイルにリダイレクトできます。

## 出力を破棄したい（`/dev/null`）

```console
// 標準出力を破棄する
$ コマンド > /dev/null
$ コマンド 1> /dev/null

// 標準エラー出力を破棄する
$ コマンド 2> /dev/null

// 標準出力と標準エラー出力を破棄する
$ コマンド &> /dev/null
```

`/dev/null`は、出力を破棄する特殊なファイルです。
いわばゴミ箱です。
リダイレクト先に`/dev/null`を指定すると、出力を破棄できます。
