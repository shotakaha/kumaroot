# 現在のパスを知りたい（`pwd`）

```bash
$ pwd     # -L と同じ
```

`pwd`コマンドで、現在のパスを確認できます。
デフォルトで表示されるパスは論理パスです。

## 論理パスを確認したい（`-L`）

```bash
$ pwd -L
```

`-L`オプションで、論理パスを確認できます。
論理パスとは、ユーザーが辿ってきたパスのことです。

## 物理パスを確認したい（`-P`）

```bash
$ pwd -P
```

`-P`オプションで、物理パスを確認できます。
物理パスとは、ファイルシステム上の実際のパスのことです。
ユーザーが辿ってきたパスに、シンボリックリンクが含まれている場合、物理パスはシンボリックリンクを解決したパスになります。
