# リダイレクトを分割したい（`tee`）

```console
// 上書き
$ コマンド | tee ログファイル名

// 追記
$ コマンド | tee -a ログファイル名
```

`tee`は、コマンドの実行結果をターミナル画面に表示しながら、ファイルにも保存できるコマンドです。

[](./command-stdout.md)で紹介したリダイレクト（`>`）を使いはじめると、すぐにぶち当たる壁があります。
それは、ファイルにリダイレクトしてしまうと、実行結果がターミナル画面に表示されないことです。
`tee`は、その不便さを解決してくれるコマンドです。

## ファイルに保存したい

```console
$ ls -la | tee output.txt
$ find . -name "*.txt" | tee results.md
```

## ファイルに追記したい（`--append`）

```console
$ コマンド | tee --append log.md
$ コマンド | tee -a log.md
```

`--append`（`-a`）オプションで、既存のファイルに追記できます。
ファイルが存在しない場合は、新規に作成します。

## 標準出力と標準エラー出力を保存したい

```console
$ コマンド 2>&1 | tee log.md
```

`2>&1`をパイプすると、標準出力と標準エラー出力の両方をターミナルに表示しながら、ファイルに保存できます。
エラーの原因を調査しているときに便利です。
