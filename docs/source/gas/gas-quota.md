# 使用制限を把握したい（クォータ）

GASには、スクリプトの実行時間やAPI呼び出し数などに上限（クォータ）があります。
無料アカウント（`gmail.com`）とGoogle Workspaceアカウントで上限が異なり、
Workspaceのほうが多くの項目で上限が高くなっています。

数値は予告なく変更されることがあります。
以下は2026年9月時点の値です。最新の値は
[Google サービスの割り当て](https://developers.google.com/apps-script/guides/services/quotas?hl=ja)
で確認してください。

:::{note}

デバッグ実行でもクォータを消費します。

:::

## 実行時間したい

| 項目 | 無料 | Workspace |
| --- | --- | --- |
| スクリプトの実行時間 | 6分 / 実行 | 6分 / 実行 |
| カスタム関数の実行時間 | 30秒 / 実行 | 30秒 / 実行 |
| トリガーの合計実行時間 | 90分 / 日 | 6時間 / 日 |

「スクリプトの実行時間」は`doGet`やトリガー関数など通常の実行の上限です。
超えるとタイムアウトします。
「カスタム関数」はスプレッドシートのセルから呼び出す関数で、別枠の短い上限です。

## 同時実行数したい

| 項目 | 無料 | Workspace |
| --- | --- | --- |
| ユーザーあたりの同時実行数 | 30 | 30 |
| スクリプトあたりの同時実行数 | 1,000 | 1,000 |

同時に走らせられるスクリプトの本数の上限です（1日あたりの回数ではありません）。
多くのユーザーが同時に呼び出すと、リクエストが遅延・失敗することがあります。

## URL取得したい（`UrlFetchApp`）

| 項目 | 無料 | Workspace |
| --- | --- | --- |
| 呼び出し数 | 20,000 / 日 | 100,000 / 日 |
| レスポンスサイズ | 50MB / 呼び出し | 50MB / 呼び出し |
| POSTサイズ | 50MB / 呼び出し | 50MB / 呼び出し |
| ヘッダー数 | 100 / 呼び出し | 100 / 呼び出し |

外部APIを`UrlFetchApp.fetch`で呼び出すときの上限です。
ウェブアプリへの受信リクエスト数に上限はありません。

## 上限を超えたときしたい

クォータを超えたり、短時間に過剰なリクエストを送ったりすると、
`Exception: Service invoked too many times`のような例外が投げられます。

一時的な制限であれば、少し待ってからリトライすると成功することがあります。

```js
function fetchWithRetry(url, maxRetries = 3) {
    for (let i = 0; i < maxRetries; i++) {
        try {
            return UrlFetchApp.fetch(url);
        } catch (err) {
            if (i === maxRetries - 1) throw err;
            Utilities.sleep(1000 * (i + 1));  // 1秒、2秒、3秒と待つ
        }
    }
}
```
